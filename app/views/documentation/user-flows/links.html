Linking to prototype pages

Each step can show two addresses: where the page is on the live service, and a link to it in the prototype.

Prototype links

The prototype field can be written in two ways. For a user flow in app/views/v3-8-0-0/:

You write It links to Use it for
"map" /v3-8-0-0/map A page in the same version. Use this most of the time.
"/v3-7-0-2/upload" /v3-7-0-2/upload A page in another version. Start with a slash.

Leave out the .html at the end. The link uses the name of the file in the version folder, so "options-radio" links to app/views/v3-8-0-0/options-radio.html.

Before adding a link, check the page exists in the version folder. If it does not, leave prototype empty until the page is built.

Live addresses

The live field is only ever shown as text, not a link. You can use placeholders for parts that change, like /results?[polygonstring].

Only add a live address if you know it. Leave it empty for pages that are not on the live service yet.
