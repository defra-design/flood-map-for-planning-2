A user flow for a new version

When you make a new prototype version, copy the user flow from the previous version and update it.

The Create a user flow skill does all of these steps for you. Ask Copilot to “create a user flow for v3.9.0.0”.

Doing it yourself

  1. Copy user-flow.html from the previous version’s folder into the new version’s folder, for example app/views/v3-9-0-0/.
  2. Update the steps for anything that has changed in this version.
  3. Check that the prototype links point to pages that exist in the new version – see linking to prototype pages.
  4. On the prototype home page, add a “View user flow” link to the new version’s card, and update the User flow link under Related links and information so it points to the new version.
  5. Add "userFlowUrl" to the version’s entry in app/views/versions.json, for example "userFlowUrl": "/v3-9-0-0/user-flow".
  6. Open the new user flow in the browser and check it loads.

You do not need to copy the wireframes. They are in a shared file, app/views/includes/user-flow/wireframes.njk, which every version uses.
