Choices and other pages

Not every journey is a straight line. Some steps give the user a choice, and some pages can be visited from more than one place.

When the user chooses one of several screens

Sometimes the user can pick one of several screens at the same point in a journey. These screens are shown side by side in a dashed box.

Example Adding a boundary

    {{ ufStep({ "type": "map", "title": "Full screen map", "live": "/map", "note": "User chooses how to add a boundary" }, 4) }} {{ ufChoiceStep({ "choice": "Add a boundary", "options": [ { "type": "draw-polygon", "title": "Draw a polygon", "live": "/map" }, { "type": "draw-square", "title": "Add a square", "live": "/map" }, { "type": "upload", "title": "Upload a boundary", "live": "/upload" } ] }, 5) }} {{ ufStep({ "type": "map", "title": "Full screen map", "live": "/map", "note": "Boundary shown on the map" }, 6) }}

In this example:

  1. At step 4, the user is on the map.
  2. At step 5, they choose one way to add a boundary. The first option says “choose one” and the others say “or”.
  3. Whichever they chose, they all go on to step 6.

The options in the box all count as one step, so the step numbers carry on as normal afterwards.

Pages outside the main flow

Some pages are not part of the journey in a set order. The user might open them from several places, or might not need them at all. For example:

  • help pages
  • guidance, such as how to use the data
  • optional pages, such as downloading a Product 1 from the results page

These are shown at the bottom of the user flow, in a dashed box called Pages outside the main flow. They have no arrows or step numbers. Instead, each one lists the pages that link to it.

Example Pages outside the main flow

If a page in the main journey links to an optional page, its note usually says so. For example, the results page says the user can optionally download a Product 1.
