Pages outside the main flow

Some pages are not visited in a set order. Add them to the otherPages list and they appear in a dashed box at the bottom of the user flow.

Example An optional page

    {{ ufOtherPage({ "type": "product1", "title": "Product 1", "prototype": "/v3-8-0-0/product-1", "note": "Optional. Printable flood map with reference details and legends", "from": ["Results page"] }) }} 
{
  "type": "product1",
  "title": "Product 1",
  "live": "",
  "prototype": "product-1",
  "note": "Optional. Printable flood map with reference details and legends",
  "from": ["Results page"]
},

They use the same fields as steps, plus from – a list of the pages that link to it. These pages have no arrows or step numbers.

What goes here

Add a page here when

  • it can be opened from several places, like a help page
  • the user does not have to visit it to carry on, like Product 1
  • it is guidance, like how to use the data

Do not add a page here when

  • every user goes through it – make it a step
  • the user must pick it or another page to carry on – use a choice step

Pointing to it from the journey

If a step in the main journey links to an optional page, add a note to that step so readers know it is there:

{ "type": "results", "title": "Results page", "live": "/results?[polygonstring]", "prototype": "results",
  "note": "User can optionally download a Product 1, see pages outside the main flow" },
