Screen types

Each step uses one of these wireframes. Designers choose the one that looks most like the real page.

The code under each screen is the type that designers use to show it. If you are just reading a user flow, you can ignore it.

If a step uses a type that is not in this list, a plain page is shown instead.

Adding a screen type

If none of these look like your page, use the closest one for now. A designer can add a new type to the shared file app/views/includes/user-flow/wireframes.njk. It then appears in every version’s user flow and on this page.

To add one, ask Copilot to use the Edit a user flow skill, or follow the notes at the top of the shared file:

  1. Draw the screen in the ufScreen macro, using the existing lines, headings and buttons.
  2. Add any new styles to ufStyles, for desktop and mobile.
  3. Add the type to the ufScreenTypes list, with a name and what it’s for.
  4. Check it fits: desktop screens are 104px tall and mobile screens are 148px. Anything below that is cut off.
