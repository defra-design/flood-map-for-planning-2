Getting started

Each prototype version has its own user flow. You change it by editing two lists at the top of one file.

You can ask Copilot to make most changes for you, using these skills:

  • Edit a user flow – add, remove or change steps, journeys and pages
  • Create a user flow – make a user flow for a new version

Where the user flow lives

For version 3.8.0.0, the file is app/views/v3-8-0-0/user-flow.html. You can view it at /v3-8-0-0/user-flow.

Other versions follow the same pattern: app/views/{version}/user-flow.html.

What to change in the file

Only edit the two lists near the top. Everything else draws the page.

How the lists are written

The lists use a format like JSON. You do not need to know it well, but you need to keep to a few rules or the page will not load:

  • put every name and value in double quotes, like "title": "Results page"
  • put a comma after every item in a list except the last one
  • keep the brackets in pairs – every { needs a } and every [ needs a ]

The easiest way to add something is to copy a line that already works and change it.

If the page stops loading after a change, see if the page does not load.
