Copilot skills for prototype management

Automated workflows to streamline prototype management and documentation

Getting started

  1. Choose a skill below based on what you need to do
  2. Click to read the full documentation and workflow
  3. When ready, run the skill in Copilot chat with your details
  4. Copilot will scaffold everything automatically

Skills in test

These skills are currently being tested and may evolve based on feedback and usage.

Skill 1: Create a new prototype version

Scaffolds a complete new version with folder structure, route files, and metadata entry.

@copilot #create-prototype-version

Use when:

  • Starting a new design iteration
  • Testing a concept with a copy of existing version
  • Ready to prototype but tags/pages not yet finalized

Skill 2: Create a design history entry

Scaffolds folder structure, post template, and metadata for documenting design changes, releases, or research findings.

@copilot #design-history-entry

Use when:

  • Release is ready to document
  • Research findings need recording
  • Design iteration reaches a milestone

Skills in Alpha

These skills have not yet been fully developed and are in the early design stages.

Skill 3: Create a page within a version

Add a new page to an existing version with route, view file, and metadata updates.

@copilot #create-page-within-version

Use when:

  • Adding pages to existing version
  • Expanding journey with new screens
  • Need page added to versions.json automatically

Skill 4: Create a page variant (split testing)

Create alternative versions of a page within same version to test different approaches or journey options.

@copilot #create-page-variant

Use when:

  • Testing two approaches to same task
  • Split testing journey options
  • Comparing design alternatives in research

Skill 5: Generate design history changelog

Create a summary of key changes and research findings from design history posts.

@copilot #generate-design-history-changelog

Use when:

  • Summarizing release for stakeholders
  • Creating release notes from research findings
  • Need quick overview of changes across versions
