Journey structure

The core user journey follows this main path:

  1. User starts at the service entry point
  2. Selects their option (query type)
  3. Enters location details
  4. Views interactive map and refines search
  5. Reviews results data
  6. Contacts support if needed
  7. Reviews summary of findings
  8. Receives confirmation

Supporting branches provide additional functionality:

  • Additional pages from Map: Users can upload boundaries, draw polygons or squares on the map, access help, view flood zone information, or learn how to use the data
  • Additional pages from Results: Users can learn how to use the data or access the Product 1 output variant
