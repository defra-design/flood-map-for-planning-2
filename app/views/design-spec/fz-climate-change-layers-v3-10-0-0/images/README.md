The map images in this folder (`map-base.jpg`, `mask-*.png`) are generated by `scripts/build-fz-climate-estimate.py`
from `source/climate-change.png`, a screenshot of the live service (Flood zones, 2070 to 2125, default layer
opacity, map only).

To use another location, replace `source/climate-change.png` (and optionally add `source/base.png`, the same view
with Datasets: None) and run the script. See "How the map is made" on the design spec overview page.

Flood zone 2 and flood zone 3 with climate change are an estimate, not flood modelling.
